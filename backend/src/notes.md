Node.js Basic Project Setup (Express)
1. What is Node.js?

Node.js is a JavaScript runtime environment.

Meaning of Runtime Environment

A runtime environment is software that allows a programming language to run outside its original environment.

JavaScript was originally designed to run only in web browsers.

Examples:

Chrome
Firefox
Edge

Node.js allows JavaScript to run on the server (outside the browser).

With Node.js you can:
Build backend servers
Create APIs
Work with files
Connect to databases
Build full backend applications
Example

Run JavaScript directly in terminal:

console.log("Hello from Node.js")

Run it using:

node app.js
2. What is Express.js?

Express.js is a web framework built on top of Node.js.

It helps you build:

Web servers
APIs
Backend applications

Without Express, creating servers in Node.js requires more code.

Express makes it simple and faster.

5. Understanding package.json

package.json is the main configuration file of the project.

It contains:

Project name
Project version
Scripts (start, dev, build)
Dependencies
Project metadata

Example:

{
  "name": "xyz-project",
  "version": "1.0.0",
  "scripts": {
    "start": "node src/app.js"
  },
  "dependencies": {
    "express": "^4.18.2"
  }
}

Developers can manually edit this file.

6. Understanding package-lock.json

package-lock.json is automatically generated by npm.

It stores the exact version of every dependency including sub-dependencies.

Purpose
Ensures the same dependency versions for everyone
Makes builds consistent across environments
Speeds up installation

Example internal dependencies:

express 4.18.2
body-parser 1.20.1
debug 2.6.9
Key Difference
File	Purpose	Edited By
package.json	Project configuration and dependencies	Developer
package-lock.json	Locks exact dependency versions	npm automatically
Important Rule

Always commit both files to Git.

Never delete package-lock.json.

7. Install Express

Install Express framework:

npm i express
Express is used to:
Create servers
Build APIs
Handle routing
Manage HTTP requests and responses

Express is widely used in MERN stack applications.

8. Install Nodemon (Development Tool)

Install globally:

npm i -g nodemon
What is Nodemon?

Nodemon automatically restarts the server when code changes.

Without nodemon:

node src/app.js

You must restart server manually.

With nodemon:

nodemon src/app.js

Server restarts automatically.

9. Running the Project
Normal run
node src/app.js
Development run
nodemon src/app.js
10. Add Scripts in package.json

Add scripts inside package.json:

"scripts": {
  "start": "node src/app.js",
  "dev": "nodemon src/app.js"
}

Now you can run:

Start server:

npm start

Development mode:

npm run dev
11. Create Basic Express Server

Create file:

src/app.js

Add code:

const express = require('express')

const app = express()

app.use('/', (req, res)=>{
    res.send('Hello from the dashboard')
})

app.use('/test',(req, res)=>{
    res.send('Hello from the test route')
})

app.listen(3000, ()=> {
    console.log('Server is started on Port 3000...')
})
12. Code Explanation
Import Express
const express = require('express')

Imports Express framework.

Create Express Application
const app = express()

Creates an Express application instance.

Create Routes
Root Route
app.use('/', (req, res)=>{
    res.send('Hello from the dashboard')
})

Visit:

http://localhost:3000

Response:

Hello from the dashboard
Test Route
app.use('/test',(req, res)=>{
    res.send('Hello from the test route')
})

Visit:

http://localhost:3000/test

Response:

Hello from the test route
Start Server
app.listen(3000, ()=> {
    console.log('Server is started on Port 3000...')
})

Server starts on port 3000.

Open browser:

http://localhost:3000

POST http://localhost:3000/signup

Postman
   ↓
Node Server (Port 3000)
   ↓
Express Router
   ↓
/signup handler

app.post('/signup', async (req, res) => {

connectDB()

16. How .save() Knows the Collection

Example model import:

const User = require('./models/user')

Model definition:

const User = mongoose.model('User', userSchema)

Mapping:

Model	Collection
User	users

When you run:

const user = new User(userObj)
await user.save()

Mongoose inserts data into:

Database → devTinder
Collection → users

18. Multiple Database Connections

Normally applications use one MongoDB connection.

But if multiple connections exist:

mongoose.createConnection(DB1)
mongoose.createConnection(DB2)

Define models per connection:

const conn1 = mongoose.createConnection(DB1)
const conn2 = mongoose.createConnection(DB2)

const User = conn1.model("User", userSchema)
const Product = conn2.model("Product", productSchema)

Then:

User.save() → DB1
Product.save() → DB2

The model decides the database.

19. Error Handling Fix

Incorrect:

res.status(500).send("Error saving user", err?.errmsg)

Correct:

res.status(500).send("Error saving user: " + err.message)

Because .send() accepts only one argument.

20. Dynamic Data with req.body

Currently you may use hardcoded data:

const userObj = {
  "firstName": "Amol",
  "lastName": "Jore"
}

Later you will use:

const user = new User(req.body)

Then:

Postman request body → database

Data becomes dynamic.
